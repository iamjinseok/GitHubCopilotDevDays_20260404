## 회의록 작성

```
너는 전문적인 문서 작성 도우미야. 내가 보낸 #file:docs/meetings/notes/20260321 회의록.txt의 두서없는 회의 메모를 분석해서, #file:docs/meetings/templates/meeting_template.md 양식에 맞춰서 깔끔한 마크다운 회의록으로 작성해 줘.

주의사항:

날짜, 참석자, 안건을 정확히 추출해서 정리해. (불참자도 명시해 줘)

논의 내용을 요약해서 핵심만 적어.

누가(Owner), 언제까지(Deadline), 무엇을(Task) 해야 하는지 Action Item을 마크다운 체크박스 - [ ]로 명확히 작성해. (잡담은 제외해)"
```

## 할 일 목록 질의
```
@workspace docs/meetings/minutes/ 폴더에 있는 모든 회의록 파일들을 분석해서, 아직 완료되지 않은 전체 할 일(To-Do) 목록을 뽑아줘.

출력 조건:

누가 어떤 업무를 언제까지 해야 하는지 표(Table) 형태로 깔끔하게 정리해 줘. (열 구성: 담당자, 할 일, 마감 기한, 출처 파일명)

잡담이나 이미 완료된 안건은 제외해 줘.
```
