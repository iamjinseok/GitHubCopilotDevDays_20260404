# 🚀 GitHub Codespaces와 Copilot으로 끝내는 스마트 문서화 워크샵

**GitHub Dev Days** 워크샵에 오신 것을 환영합니다! 🎉
본 레포지토리는 귀찮고 번거로운 회의록 작성과 프로젝트 히스토리 관리를 **GitHub와 AI(Copilot)**를 활용해 획기적으로 자동화하는 방법을 배우기 위한 실습용 템플릿입니다.

무거운 프로그램 설치 없이, 지금 보고 계신 **웹 브라우저**만 있으면 모든 실습이 가능합니다.

---

## ✅ 사전 준비 (Prerequisites)
- [x] 인터넷이 연결된 노트북 (Chrome, Edge 등 모던 웹 브라우저 권장)
- [x] **[GitHub](https://github.com/)** 개인 계정 로그인 (계정이 없다면 우측 상단 `Sign up`으로 가입해 주세요)
- [x] 워크샵용 GitHub Copilot 접근 권한 (강사 안내 참조)

---

## 🛠️ 실습 순서 (Workshop Steps)

### Step 1. 10초 만에 개발 환경 띄우기 (Codespaces)
VS Code를 설치할 필요가 없습니다. 클라우드에 나만의 완벽한 작업실을 만듭니다.
1. 방금 생성된 내 레포지토리 메인 화면에서 초록색 **`<> Code`** 버튼을 클릭합니다.
2. **`Codespaces`** 탭을 선택합니다.
3. **`Create codespace on main`** 버튼을 클릭합니다. (새 탭이 열리며 에디터 환경이 구성됩니다.)

### Step 2. AI와 함께 회의록 자동 생성하기
날것의 회의 메모를 깔끔한 마크다운 문서로 10초 만에 변환해 봅니다.
1. 좌측 탐색기에서 `docs/meetings/notes/note.txt` 파일을 만들어 아래와 같은 메모를 회의록으로 만듭니다.
```
[2026-04-03] 스마트 오피스 앱 개선 2차 기획 회의

참석자: 김팀장, 이철수(개발), 박영희(디자인), 최민수(기획)

장소: 제2회의실 및 온라인 병행

- 안건 1: 소셜 로그인 연동 이슈 및 보안 강화

철수님: 카카오/네이버 로그인 시 간헐적으로 토큰 만료 에러 발생하는 거 확인했음.

라이브러리 버전 업데이트가 필요할 것 같고, 보안 가이드라인에 맞춰서 OAuth 2.0 설정 다시 점검해야 함.

할 일: 철수님이 API 명세서 최신화하고 다음 주 수요일(4/8)까지 연동 테스트 완료하기로 함.

- 안건 2: 메인 화면 UI 컴포넌트 고도화

지난번 유저 테스트에서 폰트 가독성 지적 나옴.

영희님: 전체적으로 폰트 크기 1pt씩 키우고, 다크모드 대응해서 대비값 조정할 예정.

김팀장: 상단 배너 영역이 너무 큰 것 같으니 20% 정도 줄여서 콘텐츠가 더 많이 보이게 수정 부탁함.

할 일: 영희님이 수정된 디자인 시안(B안)을 이번 주 금요일(4/5)까지 피그마에 업로드하기.

- 안건 3: 상반기 베타 테스터 모집 계획

민수님: 4월 말에 오픈 베타 시작하려면 다음 주부터 테스터 모집 공고 나가야 함.

설문지 문항은 기획안에 있는 거 그대로 쓰되, 참여 보상(기프티콘) 예산 확인 필요.

김팀장: 예산은 승인 완료됐으니 진행하면 됨.

할 일: 민수님이 테스터 모집 공고문 초안이랑 설문지 링크 정리해서 다음 주 월요일(4/6) 오전까지 공유하기.

기타

다음 회의는 4월 10일 오후 2시 예정. 다들 일정 비워두세요. 고생하셨습니다!
```

2. 좌측 메뉴의 말풍선 아이콘(**GitHub Copilot Chat**)을 클릭하여 대화창을 엽니다.
3. 아래의 프롬프트를 복사하여 채팅창에 붙여넣고 엔터를 칩니다.

> **[프롬프트]** > 내가 보낸 `#file:docs/meetings/notes/note.txt`의 두서없는 회의 메모를 분석해서, `#file:docs/meetings/templates/meeting_template.md` 양식에 맞춰서 깔끔한 마크다운 회의록으로 작성해 줘. 
> 누가(Owner), 언제까지(Deadline), 무엇을(Task) 해야 하는지 Action Item을 마크다운 체크박스로 명확히 작성해 줘.

### Step 4. 프로젝트 전체 히스토리와 할 일(To-Do) 검색하기
특정 파일이 아닌, 프로젝트 전체 폴더를 스캔하여 필요한 정보를 추출합니다.
1. Copilot Chat 창에 아래 프롬프트를 입력합니다.

> **[프롬프트]**
> `@workspace` `docs/meetings/` 폴더에 있는 모든 문서 파일들을 분석해서, 팀원들의 전체 할 일(Action Item) 목록만 추출해 줘. 담당자별로 어떤 업무를 언제까지 해야 하는지 표(Table) 형태로 깔끔하게 정리해 줘.

## 📂 폴더 구조 안내
본 실습 레포지토리는 실무에 바로 적용할 수 있는 표준적인 문서 관리 구조를 따릅니다.

- `/docs/meetings/templates/` : 표준 회의록 마크다운 양식 보관
- `/docs/meetings/notes/` : 다듬어지지 않은 원본 회의 메모 보관
- `/docs/meetings/minutes/` : Copilot이 완성한 최종 회의록 보관
